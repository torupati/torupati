# torupati

Sensor fusion, state estimation and machine learning engineer (GNSS / MEMS IMU / LiDAR). Ph.D., Licensed Surveyor (Japan).
I turn probabilistic models, from Kalman filters to VAEs, into real-world systems.

## Start here
- study_kalman_filter: Kalman filter to IMU/GNSS EKF and factor graph optimization, derived and tested
- gnssrawmeas: GNSS raw measurement analysis (RINEX, carrier phase, widelane)
- sigmemo: noise models for sensors (PSD, random walk, Allan variance)
- cmla: classical ML algorithms (GMM, HMM) with documentation
- study_autoencoder: AE, VAE and VQ-VAE in PyTorch, from the ELBO to working models
