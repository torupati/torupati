# torupati

Sensor fusion, state estimation and machine learning engineer (GNSS / MEMS IMU / LiDAR). Ph.D., Licensed Surveyor (Japan).
I turn probabilistic models, from Kalman filters to VAEs, into real-world systems.

## Start here
- [IMU_GNSS_EKF](): Kalman filter to IMU/GNSS EKF and factor graph optimization, derived and tested
- [gnssrawmeas](https://github.com/torupati/gnssrawmeas): GNSS raw measurement analysis (RINEX, carrier phase, widelane)
- [sigmemo](https://github.com/torupati/sigmemo): noise models for sensors (PSD, random walk, Allan variance)
- [cmla](https://github.com/torupati/cmla): classical ML algorithms (GMM, HMM) with documentation
- [study_autoencoder](https://github.com/torupati/study_autoencoder): AE, VAE and VQ-VAE in PyTorch, from the ELBO to working models
